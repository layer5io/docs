# Organizations

> Guides for managing Layer5 Cloud organizations.


Use these guides to create, edit, invite members to, navigate, and delete organizations in Layer5 Cloud. For what an organization is, read [Organizations](/cloud/concepts/identity-and-security/organizations/).

| I want to | Go to |
| --- | --- |
| Create, edit, brand, switch between, or delete an organization | [Organization Management](/cloud/guides/organizations/org-management/) |
| See how the switcher and request order choose an organization | [Navigating Organizations](/cloud/guides/organizations/org-management/navigating-organizations/) |
| Nest an organization inside another | [Child Organizations](/cloud/guides/organizations/org-management/child-organizations/) |
| Send organization email through your own SMTP server | [Bring Your Own Mail Server](/cloud/guides/organizations/org-management/bring-your-own-mail-server/) |
| Choose a custom domain and identity provider | [Organization Configuration Scenarios](/cloud/guides/organizations/configuration-scenarios/) |
| Recognize members with badges | [Recognizing User and Contributor Milestones](/cloud/guides/tutorials/assigning-user-badges/) |

For people in an organization, see [Teams](/cloud/concepts/identity-and-security/teams/), [Users](/cloud/concepts/identity-and-security/users/), [User Management](/cloud/concepts/identity-and-security/users/user-management/), [User Invitations](/cloud/concepts/identity-and-security/users/user-invitations/), and [Roles](/cloud/concepts/identity-and-security/roles/). Domain changes require a Provider Admin. Creating an organization requires Create Organization, which Organization Admin and Provider Admin hold by default.
