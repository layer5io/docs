# Default User Permissions


> Complete list of default permissions granted to all users.



| Permissions                                                     | User        |
|-----------------------------------------------------------------|-------------|
| View All Users                                                  | ✅         |
| View user Profile                                               | ✅         |
| View user Designs                                               | ✅         |
| View user Badges                                                | ✅         |
| View user Activity                                              | ✅         |
| View Keys                                                       | ✅         |
| View Catalog                                                    | ✅         |
| Invite Users                                                    | ✅         |
| Update User Profile                                             | ❌         |
| Delete a user account                                           | ❌         |
| Create a new user                                               | ❌         |
| Leave a Team                                                    | ❌         |
| View Roles                                                      | ❌         |
| Assign roles to team members                                    | ❌         |
| Assign keys and keychains to the team members                   | ❌         |
