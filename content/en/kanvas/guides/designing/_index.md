These guides cover the tasks you perform while authoring a design in Designer mode. Each one accomplishes a single task and assumes you know what a design, a component, and a relationship are. If you do not, read [Designs and Components]({{< ref "kanvas/concepts/designs/index.md" >}}) and [Relationships]({{< ref "kanvas/concepts/relationships/index.md" >}}) first.

Authoring happens only in Designer mode. Operator mode shows the recorded state of your clusters and blocks adding, editing, duplicating, and deleting components.

| Goal | Guide |
|---|---|
| Add components, edit their configuration, lock, duplicate, copy, and paste them | [Add and Configure Components]({{< ref "kanvas/guides/designing/configuring-components/index.md" >}}) |
| Connect components and remove connections | [Create Relationships]({{< ref "kanvas/guides/designing/creating-relationships/index.md" >}}) |
| Draw, label, and annotate a design with shapes, text, and lines | [Whiteboard on the Canvas]({{< ref "kanvas/guides/designing/whiteboarding/index.md" >}}) |
| Keep frequently used models one step away in the dock | [Pin Models to the Dock]({{< ref "kanvas/guides/designing/pin-model-to-dock/index.md" >}}) |
| Group components by shared labels | [Work with Tags]({{< ref "kanvas/guides/designing/tagsets/index.md" >}}) |

For how Kanvas decides which relationships exist and keeps their configuration in sync, read [Policy Evaluation]({{< ref "kanvas/concepts/relationship-evaluation/index.md" >}}).
