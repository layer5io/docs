Workspaces and environments are how an organization decides which teams can reach which connections and where its designs live. These guides cover the tasks. For the model, read the [Workspaces]({{< ref "cloud/concepts/workspaces.md" >}}) and [Environments]({{< ref "cloud/concepts/environments.md" >}}) concepts. For limits, defaults, and error messages in one place, see the [Workspace and Environment Reference]({{< ref "cloud/reference/workspaces-and-environments.md" >}}).

| I want to | Go to | Permission needed |
| --- | --- | --- |
| Create, rename, or delete a workspace | [Manage Workspaces]({{< ref "cloud/guides/workspaces/managing-workspaces/index.md" >}}) | Create Workspace, Edit Workspace, Delete Workspace |
| Give a team access to a workspace's connections | [Give a team access to a workspace]({{< ref "cloud/guides/workspaces/managing-workspaces/index.md#assign-teams-to-a-workspace" >}}) | Assign team to workspace |
| Move a design or view into a workspace | [Place designs and views in a workspace]({{< ref "cloud/guides/workspaces/managing-workspaces/index.md#move-designs-and-views-between-workspaces" >}}) | Assign Designs to Workspaces, Assign Views to Workspace |
| See who changed a workspace | [Review workspace activity]({{< ref "cloud/guides/workspaces/managing-workspaces/index.md#view-recent-activity" >}}) | View Workspace |
| Create an environment and fill it with connections | [Manage Environments]({{< ref "cloud/guides/workspaces/managing-environments/index.md" >}}) | Create Environment, Assign connections to environment |
| Make an environment's connections available to a team | [Attach an environment to a workspace]({{< ref "cloud/guides/workspaces/managing-workspaces/index.md#link-environments-to-a-workspace" >}}) | Assign environment to workspace |
| Move a design from staging to production | [Promote a Design from Staging to Production]({{< ref "cloud/tutorials/promoting-a-design.md" >}}) | See the tutorial |
