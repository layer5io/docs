<div class="card-body">
    <p class="card-text">
        <p><strong>What is the purpose of this role?</strong></p>
<ul>
<li>Managing workspaces, environments, teams, and lifecycle actions, and reviewing catalog requests, in each organization where the user holds the role. It is not limited to a single workspace, and there is no Workspace Owner role that assigns it.</li>
</ul>
<p><strong>Who can assign this role?</strong></p>
<ul>
<li>An Organization Admin of that organization, a holder of Assign User Roles there, or a Provider Admin</li>
</ul>
<p><strong>When this role first assigned?</strong></p>
<ul>
<li>When an authorized administrator assigns it. Creating a workspace does not assign Workspace Admin.</li>
</ul>
<p><strong>How many instances of these roles?</strong></p>
<ul>
<li>Any number, on every plan</li>
</ul>
<p><strong>Who can remove assignment of this role?</strong></p>
<ul>
<li>The same people who can assign it</li>
</ul>
<p><strong>Workspace Manager</strong></p>
<p>Workspace Manager is the other workspace role. It includes workspace, environment, team, and lifecycle management, plus management of designs, environments, and connections inside the workspaces where the user holds the role. It does not include catalog curation. Organization Admins assign it the same way they assign Workspace Admin. See <a href="/pr-preview/pr-1364/cloud/reference/default-permissions/">Roles and Permissions</a>.</p>
<p><strong>What permissions does this role have?</strong></p>
<ul>
<li>Check <a href="/pr-preview/pr-1364/cloud/reference/default-permissions/">Permissions Reference</a></li>
</ul>
</p>
