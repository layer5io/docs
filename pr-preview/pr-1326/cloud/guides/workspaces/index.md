# Workspaces

> Guides for organizing work into workspaces and environments: who can reach which connections and where designs live.



Workspaces and environments are how an organization decides which teams can reach which connections and where its designs live. These guides cover the tasks. For the model, read the [Workspaces](/pr-preview/pr-1326/cloud/concepts/workspaces/) and [Environments](/pr-preview/pr-1326/cloud/concepts/environments/) concepts. For limits, defaults, and error messages in one place, see the [Workspace and Environment Reference](/pr-preview/pr-1326/cloud/reference/workspaces-and-environments/).
