# Workspaces

> Guides for creating, configuring, and managing Layer5 Cloud workspaces.


Workspaces and environments are how an organization decides which teams can read which connections and where its designs live. For the model, read [Workspaces](/pr-preview/pr-1210/cloud/concepts/spaces/workspaces/) and [Environments](/pr-preview/pr-1210/cloud/concepts/spaces/environments/). For limits, defaults, and error messages, see [Spaces](/pr-preview/pr-1210/cloud/concepts/spaces/).

| I want to | Go to | Permission needed |
| --- | --- | --- |
| Create, rename, or delete a workspace | [Managing Workspaces](/pr-preview/pr-1210/cloud/guides/workspaces/managing-workspaces/) | Create Workspace, Edit Workspace, Delete Workspace |
| Give a team read-only access to a workspace's connections | [Assign Teams to a Workspace](/pr-preview/pr-1210/cloud/guides/workspaces/managing-workspaces/#assign-teams-to-a-workspace) | Assign team to workspace |
| Move a design or view into a workspace | [Move Designs and Views Between Workspaces](/pr-preview/pr-1210/cloud/guides/workspaces/managing-workspaces/#move-designs-and-views-between-workspaces) | Assign Designs to Workspaces, Assign Views to Workspace |
| See who changed a workspace | [View Recent Activity](/pr-preview/pr-1210/cloud/guides/workspaces/managing-workspaces/#view-recent-activity) | View Workspace |
| Create an environment and fill it with connections | [Managing Environments](/pr-preview/pr-1210/cloud/guides/workspaces/managing-environments/) | Create Environment, Assign connections to environment |
| Make an environment's connections readable by a team | [Link Environments to a Workspace](/pr-preview/pr-1210/cloud/guides/workspaces/managing-workspaces/#link-environments-to-a-workspace) | Assign environment to workspace |
