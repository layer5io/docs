# Organizations

> Guides for administering Layer5 Cloud organizations: lifecycle, branding, domains, sign-in, email, nesting, and recognition.



These guides cover the administrator tasks for an organization, the tenant boundary in Layer5 Cloud. Each guide states which role it needs. For what an organization is and how it relates to teams, users, and roles, read the [Organizations concept](/pr-preview/pr-1332/cloud/concepts/identity-and-security/organizations/).

| I want to | Go to | Role needed |
| --- | --- | --- |
| Create, edit, brand, switch between, or delete an organization | [Manage an Organization](/pr-preview/pr-1332/cloud/guides/organizations/org-management/) | Organization Admin or Owner; Provider Admin for domains |
| Nest an organization inside another and delegate its administration | [Child Organizations](/pr-preview/pr-1332/cloud/guides/organizations/org-management/child-organizations/) | Create Organization in the parent |
| Send organization email through my own SMTP server | [Bring Your Own Mail Server](/pr-preview/pr-1332/cloud/guides/organizations/org-management/bring-your-own-mail-server/) | Organization Admin or Owner |
| Choose and set up a custom domain and identity provider | [Organization Configuration Scenarios](/pr-preview/pr-1332/cloud/guides/organizations/configuration-scenarios/) | Provider Admin for the domain, Organization Admin for providers |
| Create and award organization badges | [Recognize Members with Badges](/pr-preview/pr-1332/cloud/guides/organizations/assigning-user-badges/) | Manage Recognitions |

For the people side of an organization, see [Teams](/pr-preview/pr-1332/cloud/concepts/identity-and-security/teams/), [Users](/pr-preview/pr-1332/cloud/concepts/identity-and-security/users/), and [Roles](/pr-preview/pr-1332/cloud/concepts/identity-and-security/roles/).
