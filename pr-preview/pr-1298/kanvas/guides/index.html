How-to Guides

Task guides for building, managing, validating, deploying, sharing, and operating Kanvas designs.

Each guide accomplishes one task for a reader who already knows the basics. If you are new to Kanvas, start with Getting Started. If you want the reasoning behind a behavior, read Concepts. For exact options, limits, and shortcuts, use Reference.

Every action in these guides runs under your permissions. Kanvas hides or disables an action your role does not allow. Validating, deploying, and undeploying a design also need a Meshery you run, because the hosted kanvas.new site does not run them. How Kanvas Works with Meshery and Layer5 Cloud lists what each environment supports.

Run the steps in this order. Validation catches configuration errors in the design, a dry run checks the design against the target clusters, and a deployment applies it.
