# Tutorials

> Guided, end-to-end lessons that build a working result in Layer5 Cloud and teach the model behind it.



A tutorial here walks you through one realistic outcome from start to finish. Each one builds something you keep, such as an organization with a working team or a design deployed to production, and explains the concept behind each step as you take it. Work through a tutorial when you want to learn how the pieces fit; reach for a guide when you already know the model and need to finish one task.

| Tutorial | What you build | Before you start |
| --- | --- | --- |
| [Set Up Your Organization](/pr-preview/pr-1327/cloud/getting-started/setting-up-your-organization/) | An organization with an invited teammate, a team, a workspace, and a design in that workspace | A Layer5 Cloud account, the Organization Admin role, and a design you own |
| [Start from a Catalog Design](/pr-preview/pr-1327/cloud/getting-started/creating-a-design-from-template/) | A private copy of a published catalog design in your workspace | A Layer5 Cloud account and the Clone Design permission |
| [Promote a Design from Staging to Production](/pr-preview/pr-1327/cloud/tutorials/promoting-a-design/) | Staging and production workspaces, each with a team and an environment, and a design promoted and deployed to production | A Layer5 Cloud account, workspace and environment management permissions, a connection, and a design you own |
| [Academy Learner Guide](/pr-preview/pr-1327/cloud/academy/using-the-academy/) | Progress through Academy learning content, with badges and certificates to show for it | A Layer5 Cloud account |
